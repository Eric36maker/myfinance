# MY Finance

Tela do aplicativo MY Finance (GFC – Consultoria e Treinamentos Administrativos).

- Acesse: https://eric36maker.github.io/myfinance/

- Os arquivos são gerados por `dev/build_static.py` a partir do projeto do Apps Script; não edite à mão.
